# İngilizce Sözlüğüm — open data & license compliance

**İngilizce Sözlüğüm** is a free, fully offline Turkish ↔ English dictionary and translator for iOS and Android.
It has no ads, no accounts, no in-app purchases, and it never connects to the internet.

This repository holds everything İngilizce Sözlüğüm publishes to meet the licenses of the open data and
software it is built on:

| Path | Contents |
|---|---|
| [`ATTRIBUTIONS.md`](ATTRIBUTIONS.md) | Every third-party source used by the apps, its authors and its license |
| [`licenses/`](licenses/) | Full license texts |
| [`docs/privacy.md`](docs/privacy.md) | Privacy policy (served via GitHub Pages) |
| Releases | The İngilizce Sözlüğüm dictionary database for each app release, under CC BY-SA 4.0 |

## Dictionary database license

The İngilizce Sözlüğüm dictionary database (`lugat.sqlite`, attached to this repository's releases) is
an adaptation of Wiktionary and Tatoeba content and is licensed under the
[Creative Commons Attribution-ShareAlike 4.0 International License](licenses/CC-BY-SA-4.0.txt).
See [`ATTRIBUTIONS.md`](ATTRIBUTIONS.md) for sources and the changes made.

The İngilizce Sözlüğüm app source code is not part of this repository and is not open source.
